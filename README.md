# 🔐 Password Generator v1

A simple and customizable **password generator** built with Python and Streamlit.

The application generates random passwords based on the length and character types selected by the user.

## 🚀 Live Demo

[Password Generator v1](https://password-generator-v-1.streamlit.app/)

## ✨ Features

* Generate random passwords instantly
* Choose the password length
* Include:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special characters
* Simple and clean Streamlit interface
* Input validation for password requirements

## 🛠️ Built With

* **Python**
* **Streamlit**
* Python's built-in `random` and `string` modules
